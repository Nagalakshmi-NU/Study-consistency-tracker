# 🚀 Consistency Tracker & Learning Journal

A professional React-based web application designed to track daily learning progress, maintain study streaks, and document daily insights through a GitHub-style contribution heatmap. Built by **Nagalakshmi N U** to manage a 4-month software development internship curriculum.

## ✨ Features

* **GitHub-Style Heatmap:** Visual representation of study intensity based on topics mastered (DSA, Python, SQL, etc.).
* **Streak Counter:** Real-time calculation of consecutive study days to maintain momentum.
* **Daily Journal:** A dedicated summary section to document daily challenges and key takeaways.
* **Data Management:**
    * **Export CSV:** Generate Excel-ready reports of your learning history.
    * **Backup & Restore:** Save your progress to a JSON file and restore it anytime to prevent data loss.
* **Dynamic Filtering:** Filter history by categories like **DSA**, **Python**, or **SQL** to track specific subject progress.

## 🛠️ Tech Stack

* **Frontend:** React.js (Vite)
* **Styling:** CSS3 (Flexbox & Grid)
* **Storage:** Browser LocalStorage for persistent data.
* **State Management:** React Hooks (`useState`, `useEffect`).

## 🚀 How to Run

1.  **Clone the repository:**
    ```bash
    git clone [your-repository-link]
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    ```
4.  **Open in browser:** Navigate to `http://localhost:5173`

## 📊 Project Goals
This project serves as a tool to ensure 100% consistency over a 4-month internship period, helping to avoid gaps in learning and providing a documented history of technical growth.
